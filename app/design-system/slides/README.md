# Sample Slides

Each file is a single-slide 1920×1080 HTML using `<deck-stage>` (auto-scales). Drop any of these into a deck by copying their `<section class="slide">` into a shared `<deck-stage>` wrapper.

- `CoverSlide.html` — display-cover title, kicker, meta bar.
- `ContentSlide.html` — eyebrow + title + 2-col cards + callout takeaway.
- `SectionBreakSlide.html` — ink full-bleed chapter statement.
- `BigNumberSlide.html` — display-bignum (520px) + side caption.
- `EvidenceSlide.html` — evidence block + 3-step numbered defense.
