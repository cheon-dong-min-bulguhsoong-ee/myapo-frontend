# Web Page UI Kit

Marketing-page recreation using the design-system tokens + components. Max width 1280, padding 64.

## Components
- `WebComponents.jsx` — `WebHeader`, `Hero`, `FeatureGrid`, `Comparison`, `CTASection`, `WebFooter`, `ApplyModal`.

## Interactions
- Header nav highlights active page.
- "지금 신청" buttons open `ApplyModal`. Submit/cancel close it.
- All buttons use `.btn` (pill). Primary appears once per viewport.
