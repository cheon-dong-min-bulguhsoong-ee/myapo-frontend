# A-01.kyc — 본인 인증 (Dummy)

A-01 "발급 신청할게요" tap 후 진입. **시연용 dummy KYC** — 휴대폰 SMS 인증 형태의 폼, 실제 발송·검증 X.

## 폼 필드 (모두 필수)

1. **이름** — 텍스트
2. **주민등록번호** — 마스킹 (앞 6 + 뒤 7, 뒤 6자리는 *), 외국인 페르소나는 "외국인등록번호 또는 여권번호"
3. **휴대폰 번호** — 숫자, 우측에 "인증번호 발송" 인라인 버튼
4. **인증번호** — 6자리 숫자, 우측에 만료 카운트다운 (`03:00` → `00:00`)
5. **개인정보 제3자 제공 동의** — 체크박스 (필수, PIPA §17)
   - 라벨: "개인정보 제3자 제공에 동의해요"
   - 우측 ">" tap → bottom-sheet에 약관 본문 + 닫기
   - 약관 내용: 어떤 정보가 어느 발급기관에 어떤 목적으로 전달되는지 명시

## 동작 (Dummy)

- "인증번호 발송" tap → 카운트다운 시작 (실제 SMS 발송 X)
- 모든 필드 + 동의 체크 모두 충족 시 "발급 신청할게요" 활성
- "발급 신청할게요" tap → 가짜 로딩 1~2초 → 무조건 통과 → A-01.success 진입
- 인증번호 만료 시 → 발송 버튼 다시 활성
