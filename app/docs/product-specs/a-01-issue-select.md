## 카테고리 6종

| 카테고리 | 포함 서류 | 발급기관 |
|---|---|---|
| 신분·가족 | 가족관계증명서 / 주민등록등본 / 혼인관계증명서 / 기본증명서 | 법원·행안부 |
| 세무 | 납세증명서 / 소득금액증명원 | 국세청 |
| 사업 | 사업자등록증명원 / 휴업·폐업사실증명원 | 국세청 |
| 부동산 | 부동산등기등본 | 대법원 |
| 병역 | 병적증명서 | 병무청 |
| 보험 | 건강보험료납부확인서 / 4대보험 가입내역 | 건강보험공단 |

## Spec

- 헤드라인: "어떤 한국 서류를 발급받을까요?" / "Which Korean docs do you need?" — 페르소나별 단일 언어
- 카테고리 행: `{typography.headline}`, 우측 chevron 아이콘 (Lucide `chevron-down/up`)
- 카테고리 펼침: 클릭 시 토글, 모두 접힘 기본 진입
- 서류 카드: `card-selectable` / `card-selected`, 카드 간 12px gap, 1-column or 2-column (TBD)
- 카드 정보: 서류명 (페르소나 단일 언어) + 발급기관 `pill-neutral` (mono, 페르소나 무관)
- 선택 표시: 우상단 ✓ check 아이콘 (`primary` 색)
- 하단 버튼: `btn-primary`, "발급 신청할게요 (N)", 0개 선택 시 disabled

## 동작

- 카드 tap → 선택 토글
- 다중 선택 가능 (multi-select)
- "발급 신청할게요" tap → A-01.kyc 진입
