# S-06.detail — 분쟁 상세

S-06 카드 tap 시 진입. 신고 내용 + 운영자 응답.

## Layout

```
┌──────────────────────┐
│ ← 분쟁 상세            │ app-bar 56px
├──────────────────────┤
│ ┌──────────────────┐ │ 신고 내용 카드
│ │ 납세증명서 (영문)  │ │ headline 17 / 700
│ │ 단계 2 · 번역/공증 │ │ caption 13 / ink-secondary
│ │              [접수]│ │ pill-warning
│ │                   │ │
│ │ 사유 원문과 다름    │ │ body 15 / 500
│ │                   │ │
│ │ 영문 이름 표기가    │ │ body 15 / 500
│ │ 원본과 다릅니다.    │ │ (사용자 작성 텍스트)
│ │                   │ │
│ │ 📎 screenshot.png   │ │ 첨부 (있으면) — 이미지 thumb
│ │                   │ │
│ │ 신고일 2026-05-08   │ │ caption 13 / ink-muted
│ └──────────────────┘ │
│                      │
│ ┌──────────────────┐ │ 운영자 응답 카드 (있을 때만)
│ │ 운영자 응답         │ │ headline 17 / 700
│ │                   │ │
│ │ 검토 후 재발급      │ │ body 15 / 500
│ │ 처리하겠습니다.     │ │
│ │                   │ │
│ │ 응답 2026-05-09     │ │ caption 13 / ink-muted
│ └──────────────────┘ │
│                      │
└──────────────────────┘ (스크롤)
```

## 구조

- 신고 내용 카드 (사용자 작성)
  - 대상 서류명 + 단계 + 상태 pill
  - 사유 (라벨) + 상세 텍스트
  - 첨부 이미지 thumbnail (탭 시 풀스크린)
  - 신고일
- 운영자 응답 카드 (있을 때만 노출)
  - 응답 텍스트
  - 응답일

## 동작

- 검토중 / 접수 상태 = 운영자 응답 카드 없음 또는 "검토 중이에요" placeholder
- 종결 상태 = 운영자 응답 카드 표시
- 사용자 추가 메시지 / 답변 기능 **없음** (단방향, 운영자 응답 받기만)
