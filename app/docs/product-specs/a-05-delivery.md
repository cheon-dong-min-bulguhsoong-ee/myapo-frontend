# A-05 — 전달 중 (해외 기관 제출 진행)

A-04 bottom-sheet "보낼까요?" tap 후 진입. 선택한 기관에 credential 전달 진행 화면.

## Layout

```
┌──────────────────────┐
│ ← 전달 중              │ app-bar 56px
├──────────────────────┤
│                      │
│ 미국 영사관에         │ display 22 / 700 / -0.02em
│ 전달 중이에요          │
│                      │
│ US-CONS에            │ body 15 / 500 / ink-secondary
│ 전달하고 있어요         │
│ 잠깐만요              │
│                      │
│ ▓▓▓▓▓▓░░░░ (애니메이션)│ progress-fill or spinner
│                      │
│       (flex-grow)    │
│                      │
└──────────────────────┘ (스크롤)
```

## 4 variant

### Active — 전달 진행 중
- 헤드라인: "[기관명]에 전달 중이에요"
- 부제: "[기관코드]에 전달하고 있어요. 잠깐만요"
- 진행률 바 또는 spinner 애니메이션

### Complete — 전달 완료
- 큰 ✓ 체크 아이콘
- "전달이 완료됐어요"
- "[기관명]에서 확인할 거예요"
- `btn-primary` "확인" → S-04 복귀

### Empty — 전달 대상 없음
- "전달할 문서가 없어요"
- 부제: "A-04에서 제출 기관을 먼저 선택해요" → 와이어 카피
- (실제로는 A-05 직접 진입 케이스 거의 없음, 안전장치)

### Error — 전달 오류
- "전달 중 문제가 생겼어요"
- 부제: "다시 시도할 수 있어요"
- `btn-primary` "다시 시도할게요" + `btn-secondary` "다음에 할게요"

## Spec

- 풀스크린, 진행 중에는 ← 뒤로가기 차단 (전달 중단 방지)
- 완료 / 에러 후에는 ← 뒤로가기 가능
- 진행 시간: 가짜 2~3초 (dummy) → 무조건 완료
