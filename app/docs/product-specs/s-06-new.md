## 폼 필드

1. **단계 선택** — 해당 credential의 처리 단계 라디오 (1/2/3 자동 노출)
2. **사유 (라디오)** — `번역 오류 / 원문과 다름 / 기타`
   - 단계별로 라디오 옵션 다를 수 있음 — TBD
3. **상세 텍스트** — textarea, rows 4, placeholder "자유롭게 적어주세요", 필수
4. **스크린샷 첨부** — 선택, 이미지 1~3장 업로드

## Spec

- 분쟁 CTA = `btn-primary-danger` 토큰 사용 (`{colors.danger}` 배경) — 와이어프레임 빨강 톤 유지
- 단계 선택 / 사유 라디오: `list-row` 패턴, 활성 = ● 채워진 dot + text `{colors.primary}` (700)
- 첨부 버튼: 인라인 `btn-text-link` 형태, `paperclip` 아이콘 + 라벨

## 동작

- 모든 필수 입력 채워지면 "분쟁 신고할게요" 활성
- "분쟁 신고할게요" tap → 가짜 제출 1초 → S-06.success 진입
- "취소" tap → S-04.detail 복귀
