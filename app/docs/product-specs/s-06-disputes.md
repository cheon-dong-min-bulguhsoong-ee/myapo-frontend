# S-06 — 분쟁 내역

홈 "분쟁 내역" 진입. 내가 신고한 분쟁 기록 리스트.

## Layout

```
┌──────────────────────┐
│ ← 분쟁 내역            │ app-bar 56px
├──────────────────────┤
│ ┌──────────────────┐ │ card paper / hairline / shadow
│ │ 납세증명서 (영문)  │ │ headline 17 / 700
│ │ 단계 2 · 번역/공증 │ │ caption 13 / ink-secondary
│ │ 사유: 원문과 다름   │ │ caption 13 / ink-secondary
│ │ 신고 2026-05-08    │ │ caption 13 / ink-secondary
│ │           [접수]   │ │ pill-warning (상태별)
│ └──────────────────┘ │
│ ┌──────────────────┐ │ 다음 카드, gap 16px
│ │ ...               │ │
│ └──────────────────┘ │
└──────────────────────┘ (스크롤)
```

## 카드 정보

- 대상 서류명
- 문제 단계 (예: "단계 2 · 번역/공증")
- 사유 (라디오 선택값)
- 신고일
- 상태 pill: `접수` `검토중` `종결`

## 상태 pill 매핑

| 상태 | 컴포넌트 |
|---|---|
| 접수 | `pill-warning` (주황) |
| 검토중 | `pill-info` (파랑) |
| 종결 | `pill-neutral` 또는 `pill-success` |

## 동작

- 카드 tap → S-06.detail (분쟁 상세) 진입
- 분쟁 신청은 S-04.detail "분쟁 신청" 액션에서만 진입 (S-06 안에 + 버튼 없음)

## 빈 상태

큰 outline 아이콘(`scale` 64px ink-muted) + "신고한 분쟁이 없어요"

CTA 없음 (← 홈 복귀)
