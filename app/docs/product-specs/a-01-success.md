# A-01.success — 발급 신청 완료 알림

A-01.kyc "발급 신청할게요" 통과 후 즉시 진입. 신청 접수 acknowledgement 화면. 이후 백그라운드에서 단계 진행.

## Layout

```
┌──────────────────────┐
│                      │ app-bar 없음 또는 빈 헤더
│                      │
│       (큰 빈 공간)     │
│                      │
│         ✓             │ 큰 체크 아이콘 64px
│                      │ {colors.success}
│                      │
│ 발급 신청을 성공했어요  │ display 22 / 700 / -0.02em
│                      │ 가운데 정렬
│                      │
│ 추후 추가 서명이      │ body 15 / 500 / ink-secondary
│ 필요해요              │ 가운데 정렬
│ 알려드릴게요           │
│                      │
│       (flex-grow)    │
│                      │
├──────────────────────┤ sticky 하단
│ ┌──────────────────┐ │ btn-primary 56px
│ │ 확인               │ │
│ └──────────────────┘ │
└──────────────────────┘ safe-area-bottom + 24px
```

## Spec

- 풀스크린, 앱바 없음 (← 뒤로가기 차단 — 신청은 이미 접수됨)
- 큰 체크 아이콘 64px, `{colors.success}` `{colors.on-primary}` (Lucide `check-circle-2`)
- 헤드라인: "발급 신청을 성공했어요" 가운데 정렬
- 부제 2줄: "추후 추가 서명이 필요해요 / 알려드릴게요"
- CTA 단일: "발급 내역으로 가기" `btn-primary` → S-05 발급 내역 진입

## 동작

- "발급 내역으로 가기" tap → S-05 진입, 백 스택 정리 (A-01 / A-01.kyc 제거)
- 사용자는 S-05에서 신청한 카드 확인 → 카드 tap → S-05.detail 진행 상황
- 서명 필요 단계 도달 시 → S-05.detail 안에서 직접 서명 (bottom-sheet)
