# A-03 — 발급 완료 알림

S-05.detail에서 모든 서명 단계 완료 시 자동 등장. 풀스크린 모달 또는 push 화면.

## Layout

```
┌──────────────────────┐
│                      │ app-bar 없음
│                      │
│       (큰 빈 공간)     │
│                      │
│         ✓             │ 큰 체크 아이콘 64px
│                      │ {colors.success}
│                      │
│ 모든 서명이 끝났어요    │ display 22 / 700 / -0.02em
│                      │ 가운데 정렬
│                      │
│ 내 문서에서           │ body 15 / 500 / ink-secondary
│ 확인 가능해요          │ 가운데 정렬
│                      │
│       (flex-grow)    │
│                      │
├──────────────────────┤ sticky 하단
│ ┌──────────────────┐ │ btn-primary 56px
│ │ 확인해보겠어요?      │ │
│ └──────────────────┘ │
└──────────────────────┘ safe-area-bottom + 24px
```

## Spec

- 풀스크린, 앱바 없음
- 큰 체크 아이콘 64px, `{colors.success}` (Lucide `check-circle-2`)
- 헤드라인: "모든 서명이 끝났어요"
- 부제: "내 문서에서 확인 가능해요"
- CTA 단일: "확인해보겠어요?" `btn-primary` → S-04 내 증명서 진입

## 동작

- 진입 트리거: S-05.detail 마지막 단계 완료 시 자동 push
- 동시에 백그라운드: credential이 S-04로 이관 + S-05 리스트에서 제거
- "확인해보겠어요?" tap → S-04 진입, 백 스택 정리
- 사용자가 화면을 안 보고 있던 경우 → 푸시 알림으로 동일 정보 전달 + 앱 진입 시 표시
