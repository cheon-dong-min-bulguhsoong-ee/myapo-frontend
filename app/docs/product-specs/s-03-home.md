# S-03 — 홈 (4-메뉴 2×2)

페르소나 선택 후 진입. bottom-nav 없음, 모든 진입은 홈 카드.

## Layout

```
┌──────────────────────┐
│ MyApo                │ app-bar 56px (워드마크만)
├──────────────────────┤
│ 안녕하세요             │ display 22 / 700 / -0.02em
│                      │
│ ┌──────┐ ┌──────┐    │ 2×2 grid, gap 12px, edge 20px
│ │  📄  │ │  💼  │    │ 각 타일: card paper / hairline / shadow
│ │ 증명서 │ │ 내    │    │ aspect ~1:1, padding 24px 16px
│ │ 발급  │ │ 증명서 │    │ 아이콘 64×64 canvas / rounded-sm
│ └──────┘ └──────┘    │ 라벨 caption 13 / 600 / ink
│ ┌──────┐ ┌──────┐    │
│ │  📋  │ │  ⚖  │    │
│ │ 발급  │ │ 분쟁  │    │
│ │ 내역  │ │ 내역  │    │
│ └──────┘ └──────┘    │
└──────────────────────┘ (빈 공간)
```

## 메뉴 4종

| 위치 | 한글 | 영문 | 아이콘 | 진입 |
|---|---|---|---|---|
| 좌상 | 증명서 발급 | Issue document | `file-plus` | A-01 |
| 우상 | 내 증명서 | My documents | `wallet` | S-04 |
| 좌하 | 발급 내역 | History | `clipboard-list` | S-05 |
| 우하 | 분쟁 내역 | Disputes | `scale` | S-06 |

## 페르소나별

- 한국인 = 한글만
- 외국인 = 영문만 (UI 전체 영어 전환, 한글 노출 X)
