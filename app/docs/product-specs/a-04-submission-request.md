# A-04 — 이 문서를 요청한 기관 (제출 기관 선택)

S-04.detail "제출" 액션 tap 시 진입. 해외 기관에서 받은 제출 요청 목록 → 선택해서 보낼 곳 결정.

## Layout

```
┌──────────────────────┐
│ ← 이 문서를 요청한 기관 │ app-bar 56px
├──────────────────────┤
│ 받은 제출 요청이에요    │ display 22 / 700 / -0.02em
│                      │
│ ┌──────────────────┐ │ 요청 기관 카드
│ │ US-CONS           │ │ pill-neutral mono 13
│ │ 미국 영사관         │ │ headline 17 / 700
│ │ 비자 신청 시 필수예요│ │ body 15 / 500
│ │ 5월 9일까지 제출    │ │ caption 13 / ink-secondary
│ │ 요청 받음 5월 1일   │ │ caption 13 / ink-muted
```

## 카드 정보

- 기관 코드 pill (`US-CONS`, `AU-IMM`, `CA-IMM` 등)
- 기관명 (한글)
- 사용처 한 줄
- 마감일
- 요청 받은 날짜
- 보조 액션: "PDF로 받기" `btn-text-link` (선택적, credential 자체를 PDF로 따로 받기)

## 동작

- 카드 tap → bottom-sheet "이 문서를 요청한 기관" 등장
- bottom-sheet 내용:
  - 핸들 + 기관명 헤드라인
  - 사용처 / 마감일 / 요청 일자 detail-panel
  - `btn-primary` "보낼까요?" → A-05 (전달 중) 진입
  - `btn-secondary` "닫기"

## 빈 상태

큰 outline 아이콘 + "받은 제출 요청이 없어요"
